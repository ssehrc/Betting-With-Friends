# Betting-With-Friends
For this project, I want to learn to code without using AI. At first, I was distraught because I found it more work to research or watch a video to learn something or to figure something out. For example, I wanted to implement a database of users, but the thought was stressing me out. But when I actually learned how to do it and remembered doing it for a school project, I got the hang of it. 

Actually problem-solving instead of finding a problem and giving it to Copilot to solve has been quite rewarding. Will continue to document my process and the struggles I faced and how I overcame it.
